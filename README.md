# touchpoints-dash

Streamlit dashboard showing touchpoints by account prioritization segment, stacked by coverage.

## Run the app

```bash
uv sync
uv run streamlit run src/touchpoints_dash/app.py
```

Data is read from `src/touchpoints_dash/data/touchpoint_data.parquet` (generated by `src/touchpoints_dash/get_data.py`).

Sidebar filters cascade: Business Unit Lead, occurred_on (date range), employee, Squad, Territory, Brand, Role, USS, area.

## Tests

```bash
uv run pytest tests
```
